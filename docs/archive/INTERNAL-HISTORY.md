# Changelog

## 3.1.5 — 2026-10-21

- 为四位原创仙伴增加独立全屏提醒演出：御剑飞仙、灵符报时、草木知时、墨涟唤醒；复用已确认的角色原画与最外层手臂素材。
- 青衡改为召剑、踏剑升空、沿弧线巡游、回中落剑；人物与飞剑共用脚底支点、方向和倾斜，飞行不踩步，剑光尾迹半透明且由粗到细。
- 全屏演出使用实际时间轴与可复用的每像素透明画布，支持柔光、单显示器定位、提醒卡片避让和透明画布失败降级。
- 保留仅提示框、倒计时、减少动态、Esc 和稍后提醒；增加原生离线演出预览与回归测试，提供新版安装包和完整源码包。

## Unreleased — 2026-10-20

- 行走鞋靴改为完整刚性部件，保留靴筒、脚踝和鞋底连续形状，裤腿按实际接入点连接，不再单独压缩或扭斜鞋底。
- 小墨四肢根部固定在身体插口，只有下部迈动；校正原图比例与前后足落点，身体遮住根部，修正站立/行走/抬爪时的拼接。
- 修正头部旧衣领与新身体领口叠加导致的双领口、长颈与错位；按真实皮肤颈根校准三位人物，排除行走头层局部旧衣物，原图不变。
- 增加24相位独立头/身体皮肤重叠及旧衣领排除测试，避免仅检查躯干上单个不透明点而漏掉拼接问题。
- 修正首批侧向图中仍偏正面的身体：三位人物独立补绘侧向躯干，校准前后肩重叠、颈口及袖长，头部和灵龟不重绘。
- 四角色行走切换为经确认的新侧向原画，不再用正面投影模拟侧脸；原素材和正式安装包保留。
- 校准侧向头部原比例、颈根、肩袖与衣领遮挡；复用24相位对侧步态及原有移动逻辑。
- 增加独立侧向表情贴片，运行程序与网页预览使用相同连接点；灵龟四足按实际像素校正朝向。
- 本次只编译本地程序、更新运动预览，不生成新的安装包，等待视觉验收。

## 3.1.4 — 2026-10-20

- 按原画分别校准三位人物和灵龟的真实颈根，连接衣领/龟壳而非围绕统一头部中心旋转。
- 修正灵龟颈部下垂位置，增加壳前缘遮挡，前腿位于颈部之前；头部和壳体联动。
- 统一灵龟原画中相反方向的远侧后脚，四足趾尖随头壳整体朝向行进方向。
- 衣领前襟覆盖颈根，眨眼与张嘴统一只覆盖局部表情，不替换头部或颈部外轮廓。
- 识别不同头部原画的原生朝向；左右行走中头、衣服三分之二侧身、鞋尖统一朝向行进方向。
- 人体鞋底与小腿分开映射，脚跟/鞋尖形成朝前落地轮廓；保持对侧手脚、24相位及现有窗口移动逻辑。
- 行走专用靴子按原画脚踝与鞋尖的实际重心校正朝向，静止用腿部原画保持不变。
- 新增全部角色左右24帧方向、缩放下颈根固定、表情不改变头颈轮廓和实际颈根透明度检查。

## 3.1.3 — 2026-10-20

- 分别校准三位人物的肩口锚点，按原图实际不透明袖根居中连接，修复统一坐标与透明边距导致的偏离。
- 固定近肩袖根，向下平滑过渡到上臂摆动与肘部屈伸，避免整块肩袖旋转拉扯躯干。
- 袖子改用共享边界连续网格和完整纹理采样，消除分段裁切造成的内部透明横缝。
- 保留原画、颈部/表情联动、对侧步态与灵龟动作；新增袖根固定和网格无缝覆盖测试。

## 3.1.2 — 2026-10-20

- 行走加入以衣领/颈部为支点的轻微头部联动，采用延迟相位与柔和周期曲线，角色幅度略有不同。
- 灵龟使用更小幅度的颈部摆动和轻微伸缩；保留原有形象、手脚交叉协调和非行走动作。
- 离线帧、运行时局部表情及网页预览统一颈部变换，避免眨眼和嘴部漂移。
- 增加颈部幅度、衣领连接、连续性和循环衔接检查。

## 3.1.1 — 2026-10-20

- 手臂由整条袖子刚性旋转改为24段隐藏肘部曲线映射，加入渐进屈肘、伸展和轻微手腕滞后。
- 保持对侧手脚、原画、头型和比例；袖带重叠抗锯齿，避免透明接缝。
- 四角色行走加入独立随机节奏的眨眼与局部嘴部变化，不替换头部外轮廓。
- 表情组合位图使用72项有界缓存；缩放/换角色/关闭正确释放，减少动画时停用。
- 离线动作预览同步实机表情与变换，新增肘部、节奏和运行时缓存回归测试。

## 3.0.0 — 2026-10-20

- 以 2.3.28 功能版为基础，保留原生 Background、交互 CLI、任务历史、虚拟桌面与可见性。
- 11 个角色、身份、台词、提示词、软件图标及提醒图片改为独立原创设计。
- 新增源码绘图生成器，公开构建不读取历史图像；24 相位动作与透明超采样。
- 产品、状态目录和软件身份改为 OrbitPet；旧版本原件在独立备份中保留。
- Apache-2.0、素材授权范围、隐私/开发/贡献/安全文档、发布检查及允许列表导出。
- 本地与公开目录分离，不把密钥、模型输出、个人配置和旧素材上传到 GitHub。
- 安装器只处理本安装的进程与 Hook，混合 Hook 组保留其他处理器；卸载不递归删除用户可写目录。
