Code is distributed under Apache-2.0; see LICENSE and NOTICE.
The new cultivation-companion raster artwork in art/ is AI-assisted original
design material created for this project using the built-in imagegen editor.
The project-approved design, actual prompts and reviewed regions are included
for provenance and reproducibility. These are not exclusively hand-drawn or
code-generated illustrations; the animation frames are generated locally by
compositing the supplied transparent texture components.

To the extent the contributors hold rights that can be licensed, these artwork
files and locally rendered frames/icons are also offered under Apache-2.0.
No exclusivity, copyright eligibility, trademark clearance, or absolute
non-infringement guarantee is asserted. The maintainer should review rights
and third-party contributions before public or commercial distribution.

Current original identities: 青衡、绯笺、苍芷、小墨. Only broad public genre ideas
such as robes, cloud patterns, cultivation companionship and turtles are used;
no affiliation with an existing fictional universe is claimed.
System fonts are referenced at runtime, not redistributed as font files.

Historical assets/, work/, outputs/, excluded legacy source and backups are
not part of this public release and are not granted any license here. Use the
clean source exporter, not the entire old workspace or a web folder upload.
